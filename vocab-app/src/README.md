# 🎓 A1 İngilizce Kelime Ustası

Öğrencileriniz için hazırlanmış, 800 adet A1 seviye kelime içeren, kilit sistemli, mobil uyumlu (Android/iOS) ve oyunlaştırılmış modern kelime öğrenme uygulaması.

## 🚀 Başlangıç

Bu uygulama tamamen bağımsız (standalone) bir web uygulamasıdır. Çalıştırmak için hiçbir sunucu kurulumu, Node.js veya Python gereksinimi yoktur.

1. Klasördeki **`index.html`** dosyasına çift tıklayın.
2. Önceden tanımlanmış giriş bilgileriyle sisteme giriş yapın.

## 🌟 Güncel Özellikler

* **❓ Emin Değilim Akışı:** Sıralı kart modunda emin olunmayan kelimeler için anında Türkçe anlamı görme ve ardından karar verme sistemi.
* **📱 Android & iOS Uyumlu:** Mobil ekran boyutlarına özel kompakt kart yükseklikleri, minimum 44px dokunmatik butonlar ve sıfır taşma garantili tasarım.
* **🔒 Kademeli İlerleme:** 1. bölümdeki 100 kelimeyi tamamlamadan 2. bölüme geçiş yapılamaz.
* **🧰 Pratik Alanı:** Bilinmeyen kelimeler için Test, Boşluk Doldurma, Kelime Eşleştirme ve Kart Çalışmaları.
